# 显示组件开发规范

本规范补充 [通用维护约定](../CONTRIBUTING.md)，接口以对应提交头文件为准；历史接口见[接入指南](display-components.md)。

## 当前组件边界

- `stm_common` 只提供跨领域基础定义，不加入显示接口。
- `stm_lcd` 包含 IO、panel、touch 公共接口及薄封装，具体对象嵌入实现对象；可选 HAL 适配器单独编译，不依赖 LVGL、日志或 RTOS。
- 两个 AXS15231B 驱动实现通用面板/触摸操作表，只处理芯片协议，不依赖 HAL 或 LVGL。
- `stm_lvgl_port` 接收通用句柄、借用缓冲、时钟及空闲回调，自动连接刷新完成、输入服务和协作式 handler。
- 应用/BSP 只保留硬件配置、复位协调与对象创建；UI、彩条和诊断归应用。不增加注册中心、后台任务或 display_service。

五款旧驱动 `v0.2.0` 保留旧独立接口，不因公共框架新增就声明已迁移；原 H757 DIRECT 结论与当前 PARTIAL port 区分。

## 协议与生命周期

- 绘图右/下边界不包含，RGB565 数据紧密排列；未实现的可选能力返回 `STM_ERR_NOT_SUPPORTED`。
- 构造失败输出保持为空；面板、触摸借用 IO，port 借用设备和外部缓冲；删除不得隐式销毁共享资源。
- 每个面板只允许一个刷新接入所有者，删除前必须无在途刷新并解除自身订阅。
- IRQ 只记录状态；主循环确认 DMA/SPI 停止访问像素后才归还缓冲，完成恰好一次。保留超时、终止、错误锁存及无法安全停止时的保护；诊断关闭不关闭安全机制。
- 禁止 ISR 调用通用操作/port、递归 process、在观察回调中删除对象或调用 LVGL。HAL 全局回调由应用显式转发，适配器不占用。
- AXS 触摸保持写请求、STOP、独立读响应，不改成寄存器读；本轮单点解析。read 更新快照，get 不访问总线也不消费快照，交换轴、边界检查及镜像集中处理一次。
- port 输入默认 20 ms 采样、200 ms 过期释放、通信故障离线及 1000 ms 探测重试；畸形帧释放但不直接判为总线离线。DMA 等待期间继续服务独立 I2C，不递归进入 LVGL；恢复不自动执行共享复位。

## 代码与文档

Allman 括号、4 空格缩进，结构体成员注释放右侧。保留维护者 MIT 与必要第三方授权信息。各组件提供公开头文件、中文 README、最小示例及测试；板级示例不自动编入核心库。新增框架依赖优先 target 或同级源码，缺失明确报错，不自动下载未发布框架；已有固定版本 LVGL 获取与离线选项须保留。

## 验证与结论

覆盖 C11/C++17、真实 LVGL、独立组件、无触摸/同步/异步、生命周期/分配失败/重复完成/超时/停止失败、快照与坐标变换，并保留原有测试，不以删除测试获得通过。检查入口见 [ci/README.md](../ci/README.md)。

主机测试、完整固件链接和硬件验收分别记录；旧 tag 的板测不能代替新提交。当前 F407 验收只覆盖已说明配置的显示与触摸，不能宣称其他型号、DIRECT、长时间 soak 或既有畸形触摸帧已验证/修复。版本 tag、Release 及双平台同步仍按通用约定执行；未发布组合在 README 如实标明。
